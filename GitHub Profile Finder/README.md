# GitHub Profile Finder 🔎

A simple and responsive GitHub Profile Finder built with HTML, CSS, and JavaScript.

## 🚀 Features

- Search GitHub users
- Display GitHub profile information
- Show profile avatar
- Show username and name
- Display followers and following
- Display public repositories
- Show GitHub profile link
- Responsive design
- User-friendly interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub API
