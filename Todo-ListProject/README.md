# Todo List 📝

A simple and responsive Todo List application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Add new tasks
- Manage daily tasks
- Interactive user interface
- Responsive design
- JavaScript DOM manipulation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Todo-ListProject/
├── index.html
├── style.css
├── script.js
└── README.md
```
