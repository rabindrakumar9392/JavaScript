# Number Checker 🔢

A simple and responsive JavaScript project that analyzes a number and displays useful mathematical properties.

## 🚀 Features

- Check whether a number is positive, negative, or zero
- Check whether a number is even or odd
- Calculate the square of a number
- Generate the multiplication table from 1 to 10
- Input validation
- Enter key support
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
