# Quiz App 🧠

An interactive quiz application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Interactive quiz questions
- Answer selection
- Score tracking
- Dynamic question handling
- User-friendly interface
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Quiz-App/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the `Quiz-App` folder.
3. Open `index.html` in a browser.
