# Smart Task Manager ✅

A simple and responsive task management application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Manage daily tasks
- Task status tracking
- Responsive design
- User-friendly interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
