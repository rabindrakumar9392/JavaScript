# Expense Tracker 💰

A simple and responsive Expense Tracker application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Add expenses
- Track spending
- Display expense information
- Interactive user interface
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Expense-Tracker/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the `Expense-Tracker` folder.
3. Open `index.html` in a browser.
