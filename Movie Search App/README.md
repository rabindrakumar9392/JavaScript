# Movie Search App 🎬

A simple and responsive movie search application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Search for movies
- Display movie information
- Show movie poster
- Show movie title
- Display movie details
- API-based movie search
- Responsive design
- User-friendly interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- API
